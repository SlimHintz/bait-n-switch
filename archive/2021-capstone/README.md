# 2021 capstone (archived)

My Flatiron School data science capstone, presented in January 2021, kept as it was submitted.

- `bait-n-switch.ipynb`: the project walkthrough
- `notebooks/`: EDA, dataset creation and modelling experiments
- `slideDeck.pdf`: the final presentation
- `app.py`, `helpers.py`, `templates/`, `static/`: the Flask app that ran on Heroku
- `modules/`: helper modules the notebooks import

The notebooks expect the old layout (`src/data`, `src/modules`) and scikit-learn 0.23, so they won't run as-is from here. See the [main README](../../README.md) for what the 2026 rebuild changed and why.
